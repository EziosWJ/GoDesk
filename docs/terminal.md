# 终端与会话管理

「终端」和「会话管理」各有独立的桌面和开始菜单入口，打开后在任务栏按各自应用显示。它们共用 goDesk 管理的 Shell 会话，Shell 以 goDesk 的运行账号在被管理主机上运行。

- 每次启动「终端」都新建一个会话并打开终端窗口。创建失败时在桌面显示错误，可以再次启动重试。终端窗口显示 Shell 和底部状态栏。
- 「会话管理」只有一个窗口。列表显示会话名称、创建时间、最近接入时间及状态，可以刷新、新建、打开、改名、取得控制权和结束会话。在这里新建也会立即打开终端窗口。
- 打开已有会话时，同一桌面已有终端窗口就聚焦或恢复它。其他桌面可以打开同一会话并实时查看输出。
- 会话有人控制时，列表中的「接管」把控制权交给当前桌面的窗口，必要时先打开窗口。会话有观看者且无人控制时，按钮为「取得控制权」。当前桌面的窗口已经控制会话时，打开操作显示为「显示窗口」，隐藏控制权操作。
- 关闭窗口、关闭浏览器、退出登录或断网时，Shell 继续运行。在会话管理中确认结束会话、在 Shell 中执行 `exit` 或停止 goDesk 服务时，会话从列表移除。仍打开的终端窗口保留最后画面并显示会话已结束。

## 控制权

同一会话最多有一个控制窗口。控制窗口可以发送键盘输入和修改会话行列数。只读窗口接收相同的输出，按会话当前行列数渲染，空间不足时可以滚动。改变只读窗口的大小只影响它的可见范围。

- 会话没有连接时，第一个接入的窗口取得控制权。
- 会话已有连接时，新窗口默认只读。同一窗口用原标识替换服务端仍保留的连接时，继承该连接的角色。
- 显式取得控制权后，新控制窗口按自己的可用空间调整会话行列数，原控制窗口留在会话中并立即切为只读。
- 控制窗口断开时，仍连接的窗口保持只读。断线窗口会自动重连，按当前连接状态重新确定角色。
- 每次接入先恢复当前画面和回看，再接收实时输出。「系统设置 → 终端」可以修改默认回看行数，默认 5,000 行。设置由 SQLite 保存，修改后对新会话生效。输入 0 时只保留当前画面。

## HTTP 接口

所有接口均需要操作者登录。带请求体的接口使用 JSON。

| 方法与路径 | 请求 | 成功响应 |
| --- | --- | --- |
| `GET /api/v1/terminal/sessions` | | `200` 会话数组 |
| `POST /api/v1/terminal/sessions` | `{}` | `201` 新会话 |
| `PATCH /api/v1/terminal/sessions/{id}` | `{"name":"构建"}` | `200` 更新后的会话 |
| `DELETE /api/v1/terminal/sessions/{id}` | | `204` |
| `GET /api/v1/settings/terminal` | | `200` 终端配置 |
| `PUT /api/v1/settings/terminal` | `{"scrollbackLines":5000}` | `200` 更新后的终端配置 |

会话字段为 `id`、`name`、`createdAt`、`lastAttachedAt`、`attached`、`controllerClientId` 和 `scrollbackLines`。`attached` 表示至少有一个连接。`controllerClientId` 为控制窗口的连接标识，无控制窗口时为 `null`。时间戳采用 RFC 3339，尚未接入时 `lastAttachedAt` 为 `null`。窗口是否最小化由各自桌面决定。无效输入返回 `400`，不存在的会话返回 `404`，未登录返回 `401`。

## WebSocket

连接 `/api/v1/terminal/sessions/{id}/connect` 接入会话。客户端应在查询参数 `client` 中携带每个窗口独有的非空标识，自动重连沿用该标识。`takeover=1` 可在接入时显式取得控制权。

服务端按会话顺序发送消息。

| 帧 | 消息 | 含义 |
| --- | --- | --- |
| 文本 JSON | `{"type":"snapshot","cols":80,"rows":24,"output":"…","controller":true}` | 首条消息，包含角色、尺寸和可恢复的 ANSI 画面及回看 |
| 二进制 | PTY 输出 | 所有连接接收同一份实时输出 |
| 文本 JSON | `{"type":"control","controller":false}` | 当前连接的角色改变 |
| 文本 JSON | `{"type":"resize","cols":100,"rows":30}` | 会话行列数改变，所有连接按新尺寸渲染 |

客户端二进制帧用于输入。文本帧 `{"type":"resize","cols":100,"rows":30}` 请求调整会话尺寸，`{"type":"takeover"}` 为当前连接显式取得控制权。服务端忽略只读连接的输入和尺寸请求。

关闭码 `4404` 表示会话已结束。会话结束时服务端先发送已排队的输出。关闭码 `1013` 表示当前连接处理输出过慢，客户端可重新接入并从快照恢复。
