# 04 · 前端端口标签页

Status: ready-for-human

在「系统监控」窗口的「端口」标签页展示端口占用。

## 范围

- 仅端口标签可见时每 5 秒轮询 `/api/v1/system/ports`；离开后停止。
- 表格列：端口、协议、监听地址、进程、PID。
- 支持按端口/进程排序和按端口、协议、地址、进程、PID 筛选。
- 无归属进程显示「—」，并在页脚说明原因。
- 空结果、加载中、读取失败和无权限状态明确显示。

## 验收

- 端口列表每 5 秒刷新，排序和筛选可组合使用。
- 键盘可操作排序按钮和筛选框；表头使用 `aria-sort`。
- `pnpm --dir frontend lint` 与 `pnpm --dir frontend build` 通过。

## Comments
