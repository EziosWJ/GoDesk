# 08 · 响应式规范

视口宽度决定桌面外壳（任务栏、开始菜单、桌面网格）的排布密度与降级顺序，窗口内部通过 CSS 容器查询（`@container/app`）决定自身分栏结构。

## 桌面外壳响应规则

| 区域 | 宽屏（≥ 1024px） | 中等屏（521px – 1023px） | 窄屏（≤ 520px） |
| --- | --- | --- | --- |
| 桌面图标网格 | 左上起按列向下自动换列（`grid-auto-flow: column`） | 同左，超出工作区可平滑滚动 | 自动切换为横向多列流式网格（`grid-auto-flow: row`），方便单手纵向浏览 |
| 三段式任务栏 | 左下显示状态图标 + CPU/内存；中间自适应居中显示开始、搜索及全部固定/运行图标；右下显示快捷控制、时钟、显示桌面 | 左下优先收起 CPU/内存数值仅留健康图标与异常角标；中间仍居中，超出容量时将非激活项收进「更多应用」 | 紧凑排版，始终保证健康状态入口、开始按钮、当前激活应用与时钟可达且不缩小命中区 |
| 宽版开始菜单 | `580px` 宽居中悬浮；系统应用 5 列、扩展与快捷方式 2 列 | `min(580px, 100% - 16px)`；`< 600px` 时系统应用降为 3 列、搜索结果与扩展区降为单列 | 同左，高度限幅于任务栏上方且主区独立纵向滚动 |
| 任务栏浮层 | 按触发锚点定位并钳制在工作区左右边距内 | 同左，宽度自适应且内部滚动 | 宽度限制为 `calc(100% - 2 * inset)`，避免任何视口裁切 |

## 应用容器断点（`@container/app`）

| 容器内联宽度 | 布局能力 | 典型应用表现 |
| --- | --- | --- |
| `< 600px` | 单栏 / 顺序浏览 | 系统设置切分类列表 ↔ 详情页；文件管理器侧栏与检查器转为按需展开浮层并隐藏低优先级工具标签；服务管理转为列表 ↔ 详情 |
| `600px – 959px` (`@godesk-split/app`) | 双分栏 | 系统设置显示 Mica 导航 + 内容区；文件管理器显示侧栏 + 主文件区；系统监控概览转为两列卡片网格 |
| `≥ 960px` (`@godesk-wide/app`) | 三分栏 | 文件管理器展开属性检查器时同时呈现「侧栏 + 主列表 + 检查器」三栏对照 |

## 回流与缩放验证基线

- 窗口打开与视口缩放后，所有浮动窗口几何均由 WMKit 按当前工作区自动钳制，确保标题栏可抓取区始终可见。
- 常规验收覆盖 `1440×900`、`1280×800`、`768×1024`、`640×720` 与 `360×780` 视口，以及 200% 文本缩放与触控模式。
