# 01 · 设计原则与参考体系

goDesk 前端采用 **Windows 11（Fluent 2）现代 Web 桌面**范式，面向单台 Linux 主机和一位操作者提供多窗口运维工作台。桌面外壳负责应用启动、窗口编排与主机态势感知，各内置应用与插件专注各自内容、状态与操作。

## 设计原则

1. **原汁原味的现代桌面体验。** 多列桌面网格、三段式毛玻璃任务栏、宽版统一搜索开始菜单、贴边分屏与磁吸窗口符合 Windows 11 桌面操作直觉。选中快捷方式、固定应用、运行应用、激活窗口和键盘焦点各司其职。
2. **通透层次与克制视觉。** 以纯净中性灰阶为底座，用低透明度发丝描边、多层弥散阴影、Acrylic 磨砂浮层（任务栏、开始菜单、弹出面板、右键菜单）和 Mica 层级（窗口标题栏、侧边栏）建立清晰景深；在强制色彩模式（`forced-colors: active`）下全部安全回退为系统实色。
3. **默认系统蓝与个性化强调色。** 默认采用 Windows 11 系统蓝强调色，同时在「系统设置 → 外观」支持切换 5 组精选强调色（含原鸢尾紫）与 5 套浅/深自适应壁纸，更改即时同步到登录页、桌面、开始菜单、任务栏与所有内置应用。
4. **按任务组织信息，窗口缩放保留上下文。** 用导航定位资源，用主区完成工作，用检查器补充当前对象。容器查询驱动双栏/三分栏响应，缩放时保留选中、筛选与输入状态。
5. **兼顾精细指针、键盘与触控。** 保留完整键盘导航、焦点恢复、WCAG 2.2 AA 对比度与触控命中区；状态信息同时以颜色、图标和文字表达。

## 参考体系取舍

| 体系 | 采纳 | 按 goDesk 场景调整 | 不适用或暂缓 |
| --- | --- | --- | --- |
| Windows 11 / Fluent 2 | 三段式任务栏（左下状态胶囊、居中开始/搜索/固定与运行彩色图标、右下快捷控制/时钟/显示桌面）、宽版开始菜单、Acrylic/Mica 材质、NavigationView 左侧强调色竖条、贴角窗口三联按钮与贴边分屏预览。 | 左下角承载 Linux 主机健康与实时摘要而非天气新闻；任务栏同应用多窗口独立显示保持切换直观；默认窗口尺寸针对高分运维屏幕校准。 | 系统级热键拦截、原生系统托盘驱动、悬停最大化按钮 Snap Layouts 四宫格浮层。 |
| Apple macOS HIG | 应用内相邻窗格层级、高密度运维列表信息排版、检查器面板与全局统一外观偏好。 | 保留 Windows 11 右上贴角控制按钮和底部任务栏，不采用全局顶栏与红黄绿按钮。 | Dock 鱼眼放大、红黄绿按钮、全局顶部菜单栏。 |
| HarmonyOS UX | 区分窗口容器与内容区，按容器宽度在通栏、双分栏与三分栏间演进，区分非模态检查器与模态确认。 | 全部尺寸与断点以 Web CSS px 表达，窗口越界钳制和分屏由 WMKit 统一管理。 | 原生 `vp` 单位、系统跨设备接续。 |
| W3C 与 Tailwind CSS 4 | WCAG 2.2 AA 对比度与 APG 键盘语义；Tailwind CSS 4 `@theme inline` 与 `@container/app` 暴露 `--godesk-*` Token。 | 样式按功能模块拆分至 `frontend/src/styles/*.css`，偏好存储统一 `godesk-*` 前缀并兼容读取旧键。 | — |
