# 06 · 基础组件

尺寸、颜色和动效采用 [02](02-design-tokens.md)。下面的组件优先使用原生按钮、输入框、表格和弹窗语义，键盘行为见 [07](07-interaction-guidelines.md)。

## 选中与状态提示

- 导航项和列表行用整项 `selected` 底色表达选中。文件管理器的列表、平铺和大图标视图同时加粗选中项的名称。键盘焦点使用独立的焦点环。
- 同一区域优先突出一个主要操作，例如文件管理器的「新建文件夹」和文本编辑器的「保存」。主按钮的焦点环画在按钮外侧，与实底之间留出间隔。
- 全系统禁止用加宽的左侧或行首侧边框形成强调色条，包括导航、表格、卡片和提示框。代码评审时也检查用伪元素、内阴影或背景模拟的等效色条。布局分隔线使用 `divider` 细线。需要强调状态时使用状态文字或图标。

## 按钮与输入

| 组件 | 默认规格 | 行为与状态 |
| --- | --- | --- |
| 主按钮 | 标准高度，用 `accent` / `on-accent` | 每个操作组优先一个。用具体动词，悬停和按下使用相应强调色 Token。 |
| 次按钮 | 标准高度，中性背景；需要边界时用 `border` | 与主按钮并列时表达取消或保留。中性 hover 和 pressed 填色随主题变化。 |
| 紧凑或图标按钮 | 精细指针用紧凑尺寸，桌面壳层及标题栏按各自规格，触控达到触控目标 | 图标 16 或 20 px。提供稳定的可访问名称，悬停和键盘焦点可显示补充提示。切换按钮以 `aria-pressed` 表达持续状态。 |
| 危险按钮 | 标准高度；通常在最终确认中使用 `danger` / `on-danger` | 文案说清对象和动作。悬停可加轮廓，按下使用内绘边线，同时保持实底前景对比。 |
| 文本输入 | 标准最小高度，触控使用触控规格 | 使用可见标签。错误写在字段附近并与控件关联。搜索输入允许清除。占位文字作为提示。 |

禁用时停用操作并使用禁用语义，若需解释不可用原因，在附近提供可读说明。异步动作有明确进行中状态，阻止重复提交并保留当前对象。焦点环可与选中、悬停同时显示。 [Fluent 2 React Button](https://fluent2.microsoft.design/components/web/react/core/button/usage/)

## 表格与状态

- 使用原生表格语义，表头组织字段。表内排序按钮使用键盘可达的控件，当前排序用 `aria-sort` 表达。仅在实现完整二维键盘交互时采用 ARIA Grid。
- 表头使用 13 px / 18 px / 500，主列正文使用 14 px / 20 px / 400，12 px / 16 px / 400 留给辅助元数据。字号、行高和字重以 [字体 Token](02-design-tokens.md#字体与图标) 为准。
- 默认数据行最小 40 px，密集文本表可用 32 px。留出换行空间。可交互行按 [02](02-design-tokens.md) 放大触控热区。数字靠末端、使用等宽数字，对应表头和数据同向对齐。
- 关键信息顺序为对象标识、状态、与当前任务有关的值、低频动作。窄时优先收起非关键列，通过详情补全。仍需横向阅读时只滚动表格，并保留可见的滚动提示及键盘访问路径。
- 以文字和状态图标识别「运行中」「已停止」「失败」「未知」。已停止是中性状态，失败使用危险色，未知提供文本。行选择和运行状态使用不同标记。空、加载、错误和筛选无匹配应有不同的行内反馈。
- 行的明确操作用按钮或链接。多选用复选框，复选框和打开详情各自独立。批量操作启用时显示选中数量及作用域。

## 菜单、弹窗与反馈

| 组件 | 何时使用 | 行为 |
| --- | --- | --- |
| 命令菜单 / 右键菜单 | 锚点关联的即时命令或切换 | 按常用动作排序，危险动作独立放末端。命令项使用标准最小目标，触控使用触控目标。边缘翻转或向内偏移，较长列表可滚动。 |
| 非模态浮层 | 比主视图更贴近某个触发点的辅助信息或轻量操作 | 保持所属窗口层级，关闭后按入口恢复焦点。持续查看对象属性用检查器。 |
| 模态弹窗 | 不可逆操作、数据丢失风险、必须答复的错误 | 说明对象、后果与下一步。危险确认默认把焦点交给安全动作。整个 Web 桌面背景失去交互能力；Escape 对应取消，点击遮罩不提交也不关闭。 |
| 状态消息 | 已完成、排队、进行中或失败 | 普通完成可用短时提示。仍需处理的失败或带操作的提示保留到明确处理，优先放回相关区域。可测量的进度显示进度值，其余用不定进度。 |

React Web Desktop 模态弹窗首选宽度 440 CSS px，两侧至少 12 CSS px，内容过长时内部纵向滚动并保留操作区的可达性。用原生 `<dialog>` 的 `showModal()` 或遵守等效 APG 行为，包含标题、初始焦点、Tab 循环、Escape 和焦点归还。浏览器 top layer 模态只用于覆盖整个外壳的确认。 [Fluent 2 React Menu](https://fluent2.microsoft.design/components/web/react/core/menu/usage) · [Fluent 2 React Dialog](https://fluent2.microsoft.design/components/web/react/core/dialog/usage) · [W3C Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)
