# 05 · 前端详情、动作与日志

Status: ready-for-human

实现详情/日志标签页、动作按钮、确认流程、pending/错误反馈和能力降级。

## 范围

- 详情显示状态、原始状态、开机自启和 Description。
- 详情/日志标签页；日志首次激活加载、手动刷新、空状态和权限错误。
- 只渲染后端返回的 `actions`；生命周期与开机动作分组。
- stop/restart 弹确认框；start/enable/disable 直接执行；动作期间禁用按钮。
- 动作成功刷新列表；日志页打开时顺带刷新日志；失败内联 `role="alert"`。
- `capabilities.logs=false` 不显示日志页。

## 验收

- 停止/重启确认、动作 pending、错误提示和焦点行为可用。
- 切换服务时日志跟随当前服务；日志不超过 200 行。
- 窄窗口下保留列表/详情的串行浏览和「返回列表」。
- `pnpm --dir frontend lint` 和 `tsc -b` 通过。
