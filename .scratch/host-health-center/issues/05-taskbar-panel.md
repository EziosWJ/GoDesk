# 05 · 底栏入口与健康面板

Status: ready-for-human

用主机健康入口替换底栏右侧的浏览器网络、音量和电池控件，并实现健康面板。

## 范围

- 底栏显示整体状态图标、状态文字和异常数量；连接中断独立表达；不常驻显示资源数值。
- 点击/键盘打开面板：整体状态、异常数量、最近检查时间；警告与严重项显示原因、当前值、生效阈值和开始时间；未知项与不适用项分开展示；V1 维度摘要（CPU、内存、存储、网络）；主机名、运行时间和平台；进入系统监控的入口。
- 阈值只使用 API 返回值，不硬编码。
- 复用任务栏弹出层交互：焦点进入面板、Escape/再次激活/外部点击关闭并返回入口、非模态。
- 可访问名称包含状态与异常数量；礼貌级 live region 仅在整体状态或异常数量变化时播报；不只靠颜色。
- 窄屏先收起文字再收起次要信息，健康入口、开始、激活应用和时钟保持可见，不缩小命中区；面板内部滚动。
- 验证浅色/深色主题、键盘、200% 缩放与窄视口。

## 验收

- `pnpm --dir frontend lint`、`pnpm --dir frontend build` 通过。
- 现有桌面、窗口和系统监控功能不受影响。
