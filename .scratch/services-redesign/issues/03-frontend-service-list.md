# 03 · 前端服务列表

Status: ready-for-human

两行式列表行与选择交互。

## 范围

- 行结构：第一行 服务名（等宽、中性色）+ 开机自启小圆点 + 右对齐状态徽章；第二行 描述（灰色、单行截断）。
- 状态徽章：图标 + 文字；颜色映射 运行中=success、已完成=accent、已停止=muted、失败=danger、未知=muted。
- 单选与 ↑↓ 键盘导航（列表聚焦时即时切换选中并同步详情，无需回车）。
- 「异常置顶」排序应用；搜索命中文本在名称与描述内高亮。
- 无结果空状态 +「清除筛选」；选中项被筛掉时显示现有提示。
- 刷新/筛选/排序切换后保持选中与滚动位置。
- 不做多选、不做虚拟化。

## 验收

- ~200 行下渲染与滚动流畅，无布局跳动。
- ↑↓ 切换选中后右侧详情同步更新。
- 徽章在各状态场景下正确；自启小点仅在 `bootState=enabled` 时出现（带 title/aria-label）。
- 搜索高亮与空状态正确；「清除筛选」恢复完整列表。
- `pnpm --dir frontend lint` 与 `pnpm --dir frontend build` 通过。
