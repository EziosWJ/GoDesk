# 07 · 交互规范

鼠标、键盘与触控共享一致的命令、权限与反馈路径。窗口几何、拖拽、缩放、分屏与磁吸由 WMKit 接管，应用组件事件与焦点由 React 管理。

## 指针与键盘约定

| 交互 | 行为规则 |
| --- | --- |
| 桌面快捷方式 | 单击选中、双击打开；触控点击插件/网页快捷方式直接打开；键盘 `Enter` 启动；空白区域点击取消选中 |
| 右键与上下文菜单 | 桌面空白右键打开桌面菜单（打开终端、刷新、切换壁纸、个性化设置）；任务栏图标与开始菜单应用右键可固定/取消固定到任务栏及控制窗口；均支持 `Shift+F10` / `ContextMenu` 键 |
| 全局启动快捷键 | `Ctrl/Cmd+K`（焦点不在输入框、`.xterm` 或 `.monaco-editor` 内时）或 `Alt+Space` 打开/关闭宽版开始菜单并自动聚焦统一搜索框 |
| Escape | 优先关闭最顶层命令菜单、开始菜单或任务栏非模态浮层并恢复焦点至触发入口；模态弹窗按取消关闭；普通应用窗口不因 Escape 关闭 |
| 窗口操作 | 标题栏拖动移动（带 10px 磁吸）、拖至左/右边缘贴边半屏、拖至顶边最大化、双击标题栏切换最大化/还原、八方向调整大小并自动记忆普通态尺寸 |
| 显示桌面 | 点击任务栏最右边缘细条最小化全部当前可见窗口；再次点击仅恢复当次被最小化的窗口，不误恢复此前已手动最小化的窗口 |

## 动效与减少动效

- 窗口入场、开始菜单开关、任务栏浮层展开与贴边分屏预览均采用 `--godesk-duration-overlay`（180ms）或 `--godesk-duration-feedback`（120ms）`ease-out` 过渡。
- 最小化与还原由 WMKit 按 `minimizeTarget` 动画飞向/飞离任务栏对应图标。
- 当系统启用 `prefers-reduced-motion: reduce` 时，关闭所有窗口开合、最小化、开始菜单与分屏预览动画，状态立即切换且焦点规则不变。

## 无障碍验收基线（WCAG 2.2 AA）

- 普通正文与强调按钮、选中面对比度 ≥ **4.5:1**（当前 5 组强调色 × 浅/深 10 套组合实测最低 ≥ 4.54:1）；大文本与关键控件边界 ≥ **3:1**。
- 桌面图标文字通过浅/深壁纸自适应文字阴影保证清晰可读；在 `forced-colors: active` 下移除壁纸与毛玻璃滤镜，使用系统高对比色与单色图标回退。
- 主机健康状态仅在整体状态或异常数量发生变化时通过 `aria-live="polite"` 播报，时钟与每秒指标采样不做逐次播报。
- 精细指针控件最小 `32–36px`，粗指针触控环境（`@media (any-pointer: coarse)` / `(pointer: coarse)`）自动扩展至 `≥ 44 × 44 CSS px`。
