# 03 · 桌面外壳

goDesk 桌面外壳采用 **Windows 11 现代桌面**架构，由多列桌面工作区（`DesktopSurface`）、三段式毛玻璃任务栏（`Taskbar`）与宽版统一搜索开始菜单（`StartMenu`）构成。

## 桌面工作区与快捷方式

- **多列自动网格排布**：桌面快捷方式沿左上角起采用 `grid-auto-flow: column` 纵向填充，满一列后自动向右侧换列（极窄视口 `< 520px` 自动转为横向网格）；容器本身 `pointer-events: none` 而单项 `pointer-events: auto`，确保桌面空白区域可自由点击取消选中或触发右键菜单。
- **统一 Fluent 2 彩色应用图标**：全部 9 个内置应用（含「图标管理」）与网页快捷方式统一使用 `AppIcon` 渲染多层矢量 SVG 图标，在桌面、开始菜单、任务栏与窗口标题栏保持视觉一致；`forced-colors: active` 下自动回退为 Lucide 单色图标。
- **壁纸可读性保护**：图标文字带有按浅/深主题分别校准的柔和文字阴影，悬停呈现半透明玻璃高光，选中态叠加强调色柔和底与细边框。
- **内置 5 套自适应壁纸**：`bloom`（蓝韵花瓣，默认）、`aurora`（极光云雾）、`prism`（暮紫棱镜）、`sunset`（晨曦琥珀）、`graphite`（静谧灰阶），每套均具备浅色与深色双版 SVG 并持久化至 `godesk-wallpaper`。
- **桌面右键菜单**：空白处右键（或 `Shift+F10` / `ContextMenu` 键）提供「打开终端」「刷新」、5 套壁纸快捷切换以及「个性化设置」（直接打开系统设置 → 外观）。插件快捷方式右键提供「打开」「在新标签页打开」「移除桌面快捷方式」。

## Windows 11 三段式现代任务栏

任务栏固定在工作区底部，高度 `48px`（外加底部安全区），采用全宽 Acrylic 毛玻璃（`--godesk-acrylic-bg` + `--godesk-acrylic-blur`）与顶部 1px 发丝内高光，取消旧版 `332px` 居中限宽，划分为三个功能区：

| 区域 | 内容与交互 |
| --- | --- |
| 左下 · 主机状态胶囊 | 显示被管理主机整体健康状态图标与精简实时 CPU% / 内存%，存在告警时高亮异常计数；GoDesk 连接中断与数据过期独立表达。点击打开 Acrylic 主机健康状态面板（详情含异常原因、API 返回阈值、维度摘要与主机信息）。窄视口自动隐藏数值，仅保留状态图标与异常计数。 |
| 中间居中 · 启动与任务区 | 依次为「开始」按钮、「搜索」按钮及彩色应用图标列。默认固定「文件管理器、文本编辑器、终端、系统监控、服务管理」（持久化至 `godesk-pinned-apps`）。未运行固定项无底部标记，点击启动；已运行窗口显示 `6px` 胶囊点，激活窗口使用柔和高光底与 `16px` 强调色胶囊条。同应用多窗口（如多终端）各自独立显示并带标题提示。右键支持「固定/取消固定」「最小化/还原」「关闭窗口」「新建终端」。真正空间不足时溢出至「更多应用」。 |
| 右下 · 系统托盘 | 包含「快捷控制与通知」入口（打开 `QuickSettingsPanel`，支持即时切换浅/深/跟随主题、快捷跳转外观与系统监控、集中管理桌面提示通知，新通知到来时于右下角短暂弹出 Toast）、双行等宽数字时钟，以及最右边缘「显示桌面」细条（一键最小化全部可见窗口，再次点击还原当次最小化的窗口）。 |

## 宽版开始菜单与统一搜索

- **形态与定位**：居中悬浮于任务栏上方 `12px`，首选宽度 `580px`（窄屏自适应 `calc(100% - 16px)`），采用 Acrylic 强磨砂背景、发丝边框与多层深阴影。
- **统一搜索与快捷呼出**：顶部胶囊搜索框实时检索**内置系统应用 + 已安装的 Web 插件 + 网页快捷方式**（按名称、ID 与网址匹配），唯一匹配按 Enter 直接启动。支持点击任务栏「搜索」按钮、或全局快捷键 `Ctrl/Cmd+K`（非输入/终端/编辑器焦点时）与 `Alt+Space` 打开并自动聚焦搜索框。
- **分区内容**：非搜索态分为「系统应用」（5 列彩色网格，支持右键固定/取消固定到任务栏）与「扩展与快捷方式」（展示可用 Web 插件与网页快捷方式，空态提供前往「扩展 / 图标管理」的轻量入口）。
- **主机身份底栏**：左侧展示被管理主机名与平台架构（复用唯一一份 `useHostHealth()` 快照，不重复轮询），右侧提供「系统设置」快捷按钮与「退出登录」按钮（触发退出确认模态框）。
- **关闭与焦点**：支持 Escape、外部点击与再次点击开始按钮关闭；Escape 关闭后焦点返回开始按钮，启动窗口后焦点转入目标窗口。
