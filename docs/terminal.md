# 终端

终端在被管理主机上以 goDesk 的运行账号启动交互式 Shell。每次新建会话都打开一个独立窗口，每个窗口可以单独最小化并从任务栏恢复。点击终端启动入口时，若有运行中的会话则打开会话管理，否则直接新建会话。

## 会话管理

任意终端窗口都能打开会话管理。列表显示名称、创建时间、最近接入时间及状态，可以新建、改名、接回和结束会话。已经在当前桌面打开的会话直接聚焦原窗口，其他标签页或浏览器占用的会话由操作者主动接管。接管后原窗口提示会话已在其他位置打开。

- 关闭窗口、关闭浏览器、退出登录或断网时，Shell 继续运行。连接恢复后，原窗口自动尝试接回。刷新页面或重开浏览器后，可从会话管理接回。
- 在会话管理中确认结束或在 Shell 中输入 `exit` 时，会话从列表移除，仍打开的窗口保留最后画面并显示会话已结束。
- 停止或重启 goDesk 服务时，所有终端会话结束。会话和回看内容在 goDesk 进程内保存。
- 接回时可看到当前画面及最近的滚动输出，包括离开期间产生的内容。「系统设置 → 终端」可以修改回看行数，默认 5,000 行。设置由 SQLite 持久保存、所有浏览器共用，修改后对新会话生效。输入 0 时只保留当前画面。

## HTTP 接口

所有接口均需要操作者登录。带请求体的接口使用 JSON。

| 方法与路径 | 请求 | 成功响应 |
| --- | --- | --- |
| `GET /api/v1/terminal/sessions` | | `200` 会话数组 |
| `POST /api/v1/terminal/sessions` | `{}` | `201` 新会话 |
| `PATCH /api/v1/terminal/sessions/{id}` | `{"name":"构建"}` | `200` 更新后的会话 |
| `DELETE /api/v1/terminal/sessions/{id}` | | `204` |
| `GET /api/v1/settings/terminal` | | `200` 终端配置 |
| `PUT /api/v1/settings/terminal` | `{"scrollbackLines":5000}` | `200` 更新后的终端配置 |

会话字段为 `id`、`name`、`createdAt`、`lastAttachedAt`、`attached` 和 `scrollbackLines`。时间戳采用 RFC 3339，尚未接入时 `lastAttachedAt` 为 `null`。窗口是否最小化由各自桌面决定。无效输入返回 `400`，不存在的会话返回 `404`，未登录返回 `401`。

## WebSocket

连接 `/api/v1/terminal/sessions/{id}/connect` 接入会话。每个窗口在查询参数 `client` 中携带独立标识，自动重连沿用该标识。显式接管时另加 `takeover=1`。连接成功后的首条消息是文本 JSON 对象，包含 `type: "snapshot"`、`cols`、`rows`、`output`。客户端按快照尺寸恢复 ANSI 画面和回看，再发送实际窗口尺寸。随后的服务端二进制帧传送 PTY 输出，客户端二进制帧传送键盘输入，客户端文本帧 `{"type":"resize","cols":80,"rows":24}` 调整 PTY 尺寸。

服务端用关闭码 `4404` 表示会话已结束，`4409` 表示会话已在其他位置打开或已被接管。连接关闭会释放输入控制权，Shell 继续运行。
