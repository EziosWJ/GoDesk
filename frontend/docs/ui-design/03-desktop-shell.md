# 03 · 桌面外壳

桌面外壳提供稳定的工作区、应用入口和窗口切换。采用 Windows 熟悉的桌面、开始入口和任务栏职责，使用 React Web Desktop 的 Token 和图标。 [Windows 桌面](https://support.microsoft.com/en-us/accessibility/windows/use-a-screen-reader-to-explore-and-navigate-the-windows-desktop) · [Windows 任务栏](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows) · [Windows 开始菜单](https://support.microsoft.com/en-gb/windows/experience/personalization/customize-the-windows-start-menu)

## 桌面与快捷方式

- 桌面铺满可用视口，页面本身不滚动。工作区内的快捷方式列表可在高度不足时独立滚动。
- 快捷方式沿起始边纵向排列，图标下方居中显示名称。桌面标签、开始菜单应用标签和任务栏应用提示使用 [正文 Token](02-design-tokens.md#字体与图标) 的 14 px / 20 px / 400。桌面每项首选 88 × 80 CSS px，应用图标 42 px，项目间距 8 px。名称在文本放大时可以换行，项目随内容增高。桌面和开始菜单共用彩色应用图标，强制色彩模式使用 24 px 的单色图标。
- 单击选中，双击启动。键盘 Enter 启动，单指触控点按启动。应用已打开时激活原窗口，从最小化状态恢复。桌面空白点击清除快捷方式选择。
- 右键空白显示桌面菜单，例如刷新和切换壁纸。对象右键仅显示与对象有关的动作。菜单要有可见或键盘可到达的同等入口，例如聚焦桌面操作入口后按 `Shift+F10`。相同命令的名称和含义在各入口一致。
- 默认鸢尾壁纸在雾白或炭黑上使用低饱和紫调。桌面菜单也提供暮紫波浪和灰阶壁纸。三款均随外观切换。快捷方式名称以主题前景色直接显示在壁纸上。强制色彩模式下桌面使用系统底色。对比度要求见 [交互规范](07-interaction-guidelines.md)。

## 任务栏

| 区域 | 内容与行为 |
| --- | --- |
| 应用区 | 开始按钮与运行中的应用。空间充足时居中。运行指示持续显示，激活项使用选中底和加长的鸢尾紫底部标记。图标按钮有可读名称。 |
| 系统托盘 | 显示实际可用或明确标为模拟的状态。设备状态无交互时不使用按钮语义。 |
| 时钟 | 采用本地化时间和日期，字体使用等宽数字。读屏可主动查询，禁止每秒播报。 |

任务栏位置固定在底部，默认高度及输入命中区见 [02](02-design-tokens.md)。用 WMKit 同一份状态生成任务栏，顺序按打开顺序稳定排列，激活时不改变顺序。点击运行项激活或恢复，重复点击已激活项维持当前状态。关闭窗口后移除运行项。任务栏在普通窗口上方，应用缩放和最大化不覆盖它。

狭窄时先收起次要托盘信息，再把多余运行项放入「更多应用」。开始按钮、当前激活项、时钟与溢出入口优先保留，避免用缩小点击目标解决拥挤。 [08 响应式](08-responsive-guidelines.md)

## 开始菜单

- 菜单沿开始按钮定位，置于任务栏上方，限制在工作区内。React Web Desktop 首选宽度为 400 CSS px，窄屏两侧各留 8 CSS px，列表可独立滚动。
- 顶部为搜索，下方为应用结果。应用数量有限时，直接按名称筛选并保留默认顺序。空结果显示「未找到应用」。选择结果即启动并关闭。
- 键盘打开后焦点进入搜索。结果使用可 Tab 到达的按钮列表，Enter 在结果按钮上启动，搜索框 Enter 可启动当前唯一结果。菜单包含输入与结果，采用有标签的非模态区域。命令式右键菜单遵守 [07](07-interaction-guidelines.md) 的菜单键盘规则。
- Escape、再次点开始和外部点击关闭。键盘取消恢复到开始按钮，外部指针点击保留用户选中的新目标，启动成功后焦点进入应用窗口。
- 打开时从最终位置下方 8 CSS px 向上滑入并淡入，用浮层时长（180 ms）。关闭时向下退回 8 CSS px 并淡出，用反馈时长（120 ms）。两者均使用 `ease-out`。 [设计 Token](02-design-tokens.md#尺寸与动效)
