# 05 · 应用布局

选择能完成任务的最少窗格。Apple HIG 的分栏用于展示相邻层级，检查器可以作为附属窗格。HarmonyOS 的通栏、父子双分栏、递进式三分栏提供了对应的布局场景。React Web Desktop 同时允许三分栏的末栏由检查器承担。 [Apple Split views](https://developer.apple.com/design/human-interface-guidelines/split-views) · [Apple Panels](https://developer.apple.com/design/human-interface-guidelines/panels) · [HarmonyOS 应用设计](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/app-design-0000002353509845/)

| 布局 | 适用任务 | 窄容器行为 |
| --- | --- | --- |
| 通栏 | 单一工作面。终端、系统监控概览、单节设置、日志阅读。 | 内容跟随窗口宽度，长行按应用需求换行或在局部容器内滚动。 |
| 双分栏 | 导航＋主区，或列表＋详情。文件管理器、系统设置、服务管理中的列表与详情。 | 主区保留，导航从具名入口展开。列表＋详情改为顺序浏览并保留「返回列表」。 |
| 三分栏 | 导航＋列表＋详情，或导航＋主区＋检查器。适用于需要持续比对当前对象和属性的工作流。 | 先收起末栏，通过「查看详情」或「检查器」恢复。进一步缩窄时再折叠导航。 |

分栏尺寸和切换点见 [02](02-design-tokens.md) 与 [08](08-responsive-guidelines.md)。使用 1 px 分割线和连续的表面。需要独立滚动时保持区域名称，允许键盘用户离开滚动区。若支持拖动分隔器，提供键盘调整、恢复默认宽度和无需拖动的尺寸选项。

## 导航、工具栏与检查器

- 导航位于起始侧，用于切换资源类别或顶层区域。默认展开可用空间内的主导航，突出当前项。侧边层级建议最多两层，更深层级交给主区列表或路径。 [Apple Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars?changes=_11)
- 工具栏控制当前视图。起始侧放返回、路径或视图名称，末端放相关动作。首要动作保持可见，低频动作进入「更多」。选择行后的批量操作显示于同一工具栏范围，并写明选中数量。优先让按钮带简短文字，图标独用时补上可访问名称与工具提示。 [Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars?changes=_2)
- 检查器位于末端，标题说明关联对象。未选择对象时显示如何选择。选择变化时保持主区的选中样式和滚动位置，常用字段按属性分组。空间不足时用同一数据打开具名详情面板或视图。退出后恢复原选中对象与可用焦点。

## 信息层级与应用示例

标题栏识别应用，页面标题识别当前任务，组标题用于分区。路径仅在具有可导航层级的页面显示。优先让行、列、组标题和空白承担分组。仅在确需独立边界时使用卡片，例如可单独比较的指标摘要。

| 应用 | 推荐结构 |
| --- | --- |
| 文件管理器 | 侧边位置导航、路径与文件表格。宽容器可展开属性检查器，窄容器用「位置」和「属性」入口。 |
| 终端 | 通栏，保留等宽文本和纵向记录。长命令、固定列输出和复制使用局部策略。 |
| 系统监控 | 通栏指标摘要，图表或趋势有对应数值。宽屏可并列比较，窄屏按任务顺序堆叠。 |
| 服务管理 | 服务表格及固定作用域工具栏。状态紧邻服务名或独立状态列。将详情、日志放在检查器或串行详情视图。 |
| 系统设置 | 导航＋设置区域。窄屏以分类列表进入详情，控件变化写明是否即时生效。 |
