# 04 · 窗口规范

窗口由 `@surdeddd/wmkit` 管理几何、层级、分屏、磁吸与最小化动效，由 React（`AppWindow.tsx`）负责 Windows 11 紧凑标题栏、应用内容与组件焦点。

## WMKit 现代桌面窗口能力

goDesk 在工作区启用以下原生 WMKit 能力：

- **贴边分屏（Snap）**：`snap: { preview: true, topEdge: 'maximize' }`。拖动窗口至工作区左/右边缘展示 Fluent 2 半透明毛玻璃预览框（`[data-wm-snap-preview]`），松手自动贴合左右半屏；拖至顶边预览并最大化。
- **窗口磁吸（Magnetism）**：`magnetism: { threshold: 10 }`，窗口靠近工作区边界或相邻窗口边缘 10px 内平滑吸附对齐。
- **最小化/还原飞入动效**：`animation: true` 配合 `minimizeTarget` 定位任务栏中对应窗口项 `[data-task-app="<id>"]`（若已溢出则回退指向「更多应用」入口）；系统开启 `prefers-reduced-motion: reduce` 时自动关闭动画。
- **视口钳制与尺寸记忆**：移动窗口时保持 `minVisible: 164` 确保标题栏始终可找回；手动拖拽缩放结束后按应用分组将宽高持久化至 `godesk-window-size:<group>`（兼容读取旧键），再次打开按当前工作区自动钳制且不覆盖记忆值。

## 默认窗口尺寸基线

普通窗口最小尺寸为 `320 × 240 CSS px`，首次打开默认尺寸按高分现代桌面校准并受当前工作区钳制：

| 应用 | 默认宽 × 高 (CSS px) |
| --- | --- |
| 文件管理器 (`files`) | `920 × 600` |
| 文本编辑器 (`editor`) | `880 × 580` |
| 终端 (`terminal`) | `760 × 480` |
| 会话管理 (`sessions`) | `780 × 500` |
| 系统监控 (`monitor`) | `920 × 620` |
| 服务管理 (`services`) | `1040 × 660` |
| 扩展 (`extensions`) | `880 × 600` |
| 图标管理 (`icons`) | `720 × 500` |
| 系统设置 (`settings`) | `860 × 580` |

## Windows 11 紧凑标题栏与 Chrome

- **壳层外观**：普通窗口使用 `12px` 圆角（`--godesk-radius-window`）、1px 发丝边框（`--godesk-window-border`）与多层阴影；激活态采用 `--godesk-shadow-window-active` 与标题栏顶部微弱内高光。最大化窗口切换为 `0px` 圆角且去除外部阴影。
- **紧凑标题栏**：高度 `38px`（`--godesk-titlebar`，粗指针触控设备自动升至 `44px`），激活态采用 Mica 表面 `--godesk-mica-bg`，非激活态降为 `--godesk-mica-inactive` 并柔化标题文字对比。
- **标识与控制区**：左侧展示 `16px` 彩色 `AppIcon` 与单行省略标题；右侧为 Windows 11 经典贴角三联控制按钮（最小化、最大化/还原、关闭），每键宽 `44px` 撑满标题栏高度、无间隙贴合右上角，关闭按钮悬停 `#C42B1C`（按下 `#B22719`）配纯白图标，在普通态贴合右上窗口内圆角。
- **双击与关闭保护**：双击标题栏空白拖动区切换最大化/还原；关闭有未保存草稿的文本编辑器窗口时拦截并弹出确认对话框，确认后再执行淡出关闭。

## 堆叠层级与开合动效

- 层级从底到顶依次为：壁纸层 → 桌面快捷方式与普通窗口 → 桌面/菜单命令浮层 → 开始菜单与任务栏弹出层 → 任务栏 → Web 桌面原生 `<dialog>` 模态弹窗。
- 新建窗口从下方 `8px` 向上滑入淡入（`180ms ease-out`）；关闭窗口原地淡出（`120ms ease-out`）并立刻设为 `inert` 退出焦点与指针交互。
