# goDesk 前端术语

goDesk 前端是面向单台 Linux 主机的 Windows 11（Fluent 2）风格 Web 桌面界面。

## 术语

**桌面外壳**

承载应用启动、窗口编排与主机态势感知的公共桌面界面，包含桌面工作区（`DesktopSurface`）、三段式现代任务栏（`Taskbar`）和宽版开始菜单（`StartMenu`）。

**桌面工作区**

扣除任务栏与底部安全区后的窗口坐标空间，包含多列自动网格排布的桌面快捷方式与全部应用窗口。

**任务栏**

固定在桌面底部的 48px 高 Acrylic 毛玻璃底栏，分为左下主机状态胶囊、居中启动与任务区、右下系统托盘三段。

**固定应用（Pinned App）**

操作者固定在任务栏居中区的常用应用入口（默认包含文件管理器、文本编辑器、终端、系统监控、服务管理），未运行时可直接启动，配置持久化在浏览器本地存储中。

**开始菜单**

点击任务栏「开始」或「搜索」按钮（或按 `Ctrl/Cmd+K`、`Alt+Space`）打开的宽版居中 Acrylic 启动面板，包含覆盖系统应用、Web 插件与网页快捷方式的统一搜索、分区图标网格和主机身份底栏。

_避免使用_：「菜单栏」。

**快捷控制与通知**

位于任务栏右下角的非模态 Acrylic 浮层（`QuickSettingsPanel`），聚合主题快速切换、外观与系统监控快捷跳转以及桌面提示/错误通知列表。

**显示桌面**

位于任务栏最右边缘的细条按钮，一键最小化当前所有可见窗口，再次点击还原当次最小化的窗口。

**贴边分屏（Snap）**

将窗口拖至工作区左/右边缘或顶边时触发的半透明预览与自动半屏/最大化排布交互。

**个性化画廊**

「系统设置 → 外观」中的可视化配置区，提供主题模式预览卡片、5 组强调色色板和 5 套浅/深自适应壁纸缩略图画廊。
