# 05 · 应用布局

应用内部遵循“最少必要窗格”原则，依据窗口内容区宽度（`@container/app`）在通栏、双分栏和三分栏间平滑演进。

| 布局 | 适用场景 | 窄容器行为（`< 600px`） |
| --- | --- | --- |
| 通栏 | 终端、系统监控概览、图标管理、扩展列表 | 跟随容器宽度纵向排版，表格与日志局部滚动 |
| 双分栏 | 系统设置（导航＋内容）、服务管理（列表＋详情） | 改为顺序浏览，提供显式「返回」入口并恢复焦点 |
| 三分栏 | 文件管理器（侧栏＋主列表＋属性检查器） | 先折叠检查器，再折叠侧栏为浮层面板，通过工具栏按钮按需展开 |

## 导航、工具栏与表面层次

- **Mica 导航侧栏**：系统设置与文件管理器的左侧导航使用 `--godesk-mica-bg`（与纯白/深灰主内容面形成轻微明暗分离），当前选中项同时具备 `--godesk-selected` 底色、强调色文字与 Windows 11 风格左侧 `3px` 圆角强调色竖条。
- **紧凑工具栏**：工具栏贴近所控制的内容视图；文件管理器将路径导航栏与操作栏收紧为 `38px` 高、通过细竖线合理分组，避免中等窗口宽度下按钮拥挤或裁切。
- **检查器与详情**：属性检查器保持非模态协同，切换选中对象实时更新字段而不丢失列表滚动位置。

## 核心内置应用结构

| 应用 | 布局与视觉重点 |
| --- | --- |
| 文件管理器 | 38px 紧凑路径栏与操作栏 + Mica 左侧快速访问侧栏 + 列表/平铺/大图标主区 + 按需展开的属性检查器 |
| 系统设置 | Mica 左侧分类导航 + 「外观」Win11 个性化画廊（可视化主题预览卡、5 组强调色点、5 套壁纸缩略图画廊）+ 「常规」真实环境摘要 + 终端与账户密码设置 |
| 系统监控 | 概览 / 端口双标签；概览采用 Fluent 2 层次卡片、100px 高 SVG 渐变面积折线图与鼠标悬停精确读数、多核柱状图、磁盘与网卡卡片；端口支持筛选、排序、进程树与日志查看 |
| 服务管理 | 可拖拽左右分栏（列表＋详情/日志）、计数筛选 chips、状态徽章、开机自启开关与日志搜索 |
| 终端 / 会话管理 | 终端通栏 xterm 适配当前主题变量；会话管理列表展示活跃/控制状态与快捷接管/重命名/结束操作 |
| 登录页 | 同步桌面当前自适应壁纸与亮/暗主题，居中 Acrylic 强磨砂卡片与全局强调色主按钮，与桌面保持连续一体感 |
