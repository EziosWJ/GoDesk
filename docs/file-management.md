# 文件管理与文本编辑

## 操作约定

- 默认打开 goDesk 运行账号的主目录。侧栏提供主目录和根目录，地址栏接受 Linux 绝对路径。保留面包屑、历史导航、当前目录名称筛选、隐藏文件开关及列表和网格布局。进入目录、写操作完成和手动刷新时读取主机。跳转失败时保留当前位置。当前位置失效时可返回上级或主目录。
- 主文件管理器和文件对话框的地址栏都可以点击当前目录名或空白处，切换到绝对目录路径输入并全选。点击上级面包屑直接跳转。Enter 提交，Esc 退出路径编辑。跳转失败时保留当前位置和输入，并显示原因。保存对话框切换目录时保留文件名和保存类型。
- 「保存新文件」「另存为」和复制、移动的目标目录对话框可拖动右下角调整宽高。文件列表随对话框扩展，底部操作按钮保持可见。同一浏览器内共用上次手动调整的尺寸，打开时按可用窗口空间限制尺寸。小屏幕使用自适应布局，临时窗口尺寸变化不会覆盖记忆值。
- 显式指定的新建目录名或重命名遇到同名时提示换名。主窗口新建目录时会选一个可用的临时名称，并进入改名状态。上传、复制和移动遇到同名时可跳过或保留两者。保留两者生成如 `报告 (1).txt` 的名称，后端在提交时确保目标可用。
- 复制、移动和永久删除支持多选及目录树。删除前显示名称和数量，并确认一次。批量处理返回每项结果。上传或复制失败时清理不完整目标，可单独重试。跨挂载点移动先完整复制目标再删除源，若删除失败，保留已经创建的目标并报告源可能仍有内容。
- 可打开指向可访问目录或普通文件的符号链接。复制、移动、重命名和删除操作链接本身。断链仍可管理，打开时显示错误。
- 列表展示每项的所有者、所属组和 Linux 权限标识，网格可在「属性」面板查看。所有者、所属组优先显示名称，查不到时显示数字 UID、GID。权限采用 `ls -l` 的十字符格式（包含类型和特殊权限位），属性面板同时展示八进制值。符号链接及断链展示链接本身的属性。FIFO、套接字和设备文件仅展示属性。
- 在「属性」面板可修改单个普通文件、目录或符号链接的所有者和所属组。接受名称或十进制 ID，一次可修改两项，只更新实际改动的字段。目录只修改自身，符号链接和断链只修改链接本身。修改由 goDesk 运行账号执行，Linux 决定是否允许。成功后从主机重新读取属性，失败则保留输入并显示原因。复制和跨挂载点移动沿用目标位置的 Linux 归属规则。
- 在「属性」面板可修改单个普通文件或目录的权限，接受三位或四位八进制值，例如 `644`、`0755` 和 `1777`。目录只修改自身。goDesk 运行账号执行修改，由 Linux 决定是否允许。提交成功后从主机重新读取属性，失败则保留输入并显示原因。
- 「属性」面板将「修改所有权」和「修改权限」放在同一组，「打开」或「下载」单独放在下一行。发布构建从主机的本地账号文件解析名称。只通过外部身份服务提供的账号可使用数字 UID 或 GID。
- 上传支持一次选择或拖入多个本地文件，目标为当前目录，并显示进度和逐项结果。下载支持单个普通文件。上传和下载使用 HTTP 流，无应用层文件大小上限。文件夹上传、打包下载、批量下载、真实预览、回收站、撤销和 ZIP 解压留到后续。
- 编辑器支持新建、打开、保存、另存为和关闭前提示。支持 `.txt`、`.md`、`.log` 和 `.json` 的 UTF-8 文本，单文件最大 5 MiB。保存前检查版本。文件被外部修改、移动或删除时保留草稿，可另存为。通过 goDesk 文件管理器移动或重命名时，打开的标签页跟随新路径。另存为遇到同名可换名或保留两者。
- 保存原文件时保留原所有者和所属组，按 Linux 规则恢复原权限位。无法保留所有权或权限不足时，保留原文件和草稿，显示文件路径与失败原因，并提供「另存为」。打开文件权限不足时显示文件路径与原因。需要提权修改受保护的系统配置时，在 SSH 或主机终端使用 `sudoedit`，由主机处理 sudo 授权和密码提示。

## HTTP 接口

所有接口使用现有操作者会话，前缀为 `/api/v1/files`。路径为 Linux 绝对路径，名称为单个目录项。操作以运行 goDesk 的 Linux 账号执行。

| 方法和路径 | 请求 | 成功响应 |
| --- | --- | --- |
| `GET /directory` | 查询参数 `path`，省略时打开主目录 | `{path, home, entries}` |
| `POST /action` | JSON `{operation, path, destination?, name?, conflict?}` | `{path}`，跳过时附 `skipped: true`，跨挂载点移动成功时附 `copied: true` |
| `PUT /ownership` | JSON `{path, owner?, group?}`，至少提供一项 | `{path}` |
| `PUT /permissions` | JSON `{path, mode}`，`mode` 为三位或四位八进制字符串 | `{path}` |
| `POST /upload` | 查询参数 `directory`、`name`、`conflict?`，请求体为 `application/octet-stream` 文件字节 | `{path}`，跳过时附 `skipped: true` |
| `GET /download` | 查询参数 `path` | 附件形式的文件字节 |
| `GET /text` | 查询参数 `path` | `{path, text, version}` |
| `PUT /text` | JSON `{path, text, version?, conflict?}` | `{path, version}` |

`entries` 每项包含 `name`、`path`、`kind`、`size`、`owner`、`group`、`permissions`、`mode`。其中所有者和所属组为显示名称或数字字符串。`mode` 为四位八进制权限字符串。符号链接附带 `targetKind` 或 `targetError`。目录类型为 `directory`，普通文件为 `file`，符号链接为 `symlink`。

`operation` 取 `mkdir`、`rename`、`copy`、`move` 或 `delete`。新建时 `path` 是父目录。重命名和新建提供 `name`。复制和移动提供目标目录 `destination`。批量由前端逐项调用，保留每项结果。未指定 `conflict` 时返回同名错误。复制、移动和上传接受 `keep` 或 `skip`，创建文本接受 `keep`。

保存原文件时传入读取或上次保存取得的 `version`。编辑器在实际目标目录中写入临时文件，再原子替换原文件，因此保存原文件需要写入该文件和实际目标目录的权限。创建文本时省略版本。文件操作失败返回 JSON `{code, message, path?}`。未登录返回 401。常见文件错误包括路径无权限（403）、路径不存在（404）、同名或版本变化（409）、文本超限（413）、不支持的文件类型（415）。跨挂载点移动无法清理源时，`code` 为 `source_cleanup_failed`，`path` 为已完成的目标路径。

无效账号和无效权限分别返回 `invalid_account` 和 `invalid_mode`（400）。保存原文件时无法保留所有权返回 `ownership_preservation_failed`（403）。
