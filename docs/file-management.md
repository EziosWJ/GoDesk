# 文件管理与文本编辑

## 操作约定

- 默认打开 goDesk 运行账号的主目录。侧栏提供主目录和根目录，地址栏接受 Linux 绝对路径。保留面包屑、历史导航、当前目录名称筛选、隐藏文件开关及列表和网格布局。进入目录、写操作完成和手动刷新时读取主机。跳转失败时保留当前位置。当前位置失效时可返回上级或主目录。
- 主文件管理器和文件对话框的地址栏都可以点击当前目录名或空白处，切换到绝对目录路径输入并全选。点击上级面包屑直接跳转。Enter 提交，Esc 退出路径编辑。跳转失败时保留当前位置和输入，并显示原因。保存对话框切换目录时保留文件名。
- 「保存新文件」「另存为」和复制、移动的目标目录对话框可拖动右下角调整宽高。文件列表随对话框扩展，底部操作按钮保持可见。同一浏览器内共用上次手动调整的尺寸，打开时按可用窗口空间限制尺寸。小屏幕使用自适应布局，临时窗口尺寸变化不会覆盖记忆值。
- 显式指定的新建目录名或重命名遇到同名时提示换名。主窗口新建目录时会选一个可用的临时名称，并进入改名状态。上传、复制和移动遇到同名时可跳过或保留两者。保留两者生成如 `报告 (1).txt` 的名称，后端在提交时确保目标可用。
- 复制、移动和永久删除支持多选及目录树。删除前显示名称和数量，并确认一次。批量处理返回每项结果。上传或复制失败时清理不完整目标，可单独重试。跨挂载点移动先完整复制目标再删除源，若删除失败，保留已经创建的目标并报告源可能仍有内容。
- 可打开指向可访问目录或普通文件的符号链接。复制、移动、重命名和删除操作链接本身。断链仍可管理，打开时显示错误。
- 列表展示每项的类型、修改时间、所有者、所属组、Linux 权限标识和大小，网格可在「属性」面板查看。修改时间按本地 24 小时制显示（悬停提示完整时间与 RFC 3339 时间戳）。列表表头和工具栏「排序」支持按名称、类型、修改时间、大小升序或降序排列，平铺与大图标视图同步应用同一排序；文件夹始终置顶于文件之前，默认按名称升序，排序偏好持久化在 `localStorage`（`godesk-files-sort`）。所有者、所属组优先显示名称，查不到时显示数字 UID、GID。权限采用 `ls -l` 的十字符格式（包含类型和特殊权限位），属性面板同时展示八进制值。符号链接及断链展示链接本身的属性。FIFO、套接字和设备文件仅展示属性。
- 在「属性」面板可修改单个普通文件、目录或符号链接的所有者和所属组。接受名称或十进制 ID，一次可修改两项，只更新实际改动的字段。目录只修改自身，符号链接和断链只修改链接本身。修改使用当前操作身份，Linux 决定是否允许。成功后从主机重新读取属性，失败则保留输入并显示原因。复制和跨挂载点移动沿用目标位置的 Linux 归属规则。
- 在「属性」面板可修改单个普通文件或目录的权限，接受三位或四位八进制值，例如 `644`、`0755` 和 `1777`。目录只修改自身。修改使用当前操作身份，Linux 决定是否允许。提交成功后从主机重新读取属性，失败则保留输入并显示原因。
- 「属性」面板将「修改所有权」和「修改权限」放在同一组，「打开」单独放在下一行。发布构建从主机的本地账号文件解析名称。只通过外部身份服务提供的账号可使用数字 UID 或 GID。
- 上传支持一次选择或拖入多个本地文件，目标为当前目录，并显示进度和逐项结果。选中单个普通文件可直接流式下载；选中单个文件夹或多个可管理项时，先通过 `HEAD` 预检可读性，再由浏览器直接流式打包下载为 `.zip`（不经 Blob 内存缓冲）。上传和下载使用 HTTP 流，无应用层文件大小上限。文件夹上传、回收站和撤销留到后续。
- 支持归档压缩与解压：选中 1 个或多个可管理项时，右键菜单提供「压缩为 ZIP…」，默认生成 `<单选项名>.zip` 或 `<当前目录名>.zip` 到当前目录，遇同名（`409 exists`）可换名或选择「保留两者」。选中单个 `.zip`、`.tar`、`.tar.gz` 或 `.tgz` 文件（大小写不敏感）时，右键菜单提供「解压到同名文件夹」和「解压到当前目录」，遇同名冲突弹出「跳过同名项 / 保留两者」对话框，越界路径（`path_traversal`）和损坏归档（`invalid_archive`）返回明确中文提示。所有打包下载、压缩与解压操作均沿用当前普通/管理员身份。
- 文件夹右键菜单和当前目录空白处右键菜单提供「在此打开终端」，以目标目录为初始工作目录新建并聚焦终端窗口。终端始终以 goDesk 运行账号启动；若管理员模式下浏览的目录对运行账号无权限，返回明确权限错误提示而不隐式提权。
- 双击普通文件或按 Enter 可打开文件。PNG、JPEG、GIF、WebP、BMP、ICO 和 SVG 文件在图片预览中打开，右键「预览」也可打开同一查看器。读取使用文件管理器当前的操作身份。图片加载失败时显示原因。
- 其余普通文件在编辑器中打开。右键菜单的「预览」通过同一文本接口读取当前内容，在单独的只读标签页中展示。二进制内容、不支持的编码、权限不足和文件超限各有错误提示。下载由用户通过「下载」发起。
- 打开时读取并校验单文件最多 5 MiB 的完整内容。支持无 NUL 字节的 UTF-8，包括 `/etc/hosts`、`/etc/fstab` 和 `.conf`。按文件名与扩展名选择编辑器的轻量 Monarch 语法高亮（保留 JSON 语言服务，不增加额外 Web Worker），支持 Markdown、JSON、YAML（`.yaml`/`.yml`）、INI/配置与 systemd 单元（`.ini`/`.conf`/`.cfg`/`.service`/`.socket`/`.timer`/`.target`/`.mount`/`.path`/`.slice`/`.env`/`.env.*`）、Shell（`.sh`/`.bash`/`.zsh`/`.bashrc`/`.zshrc`/`.profile`）、TOML（`.toml`）、XML/SVG（`.xml`/`.svg`）、HTML（`.html`/`.htm`）、CSS（`.css`）、SQL（`.sql`）、Dockerfile（`Dockerfile`/`Dockerfile.*`/`.dockerfile`）、Python（`.py`）、Go（`.go`）、JavaScript（`.js`/`.mjs`/`.cjs`/`.jsx`）和 TypeScript（`.ts`/`.tsx`）。目录列表只读取目录项元数据。
- 编辑器支持新建、工具栏「打开文件…」（复用主机文件位置对话框，沿用当前普通/管理员身份打开主机文件，`Ctrl+O` 快捷打开）、保存、另存为、重新加载和关闭前提示。状态栏提供自动换行开关（`on`/`off`）与字号控制（`11px`–`28px`，默认 `14px`，支持点击重置及 `Ctrl+滚轮` 缩放），两项偏好持久化在 `localStorage`。保存前检查版本：遇到外部修改冲突（`409 changed`）时弹出三选一冲突对话框，可选择重新加载磁盘版本（放弃本地修改）、另存为新文件或取消；普通与管理员模式均适用。已保存文件标签页可随时点击「重新加载」按当前标签页身份从磁盘重读，存在未保存修改时先二次确认。文件被移动或删除时保留草稿，可另存为。通过 goDesk 文件管理器移动或重命名时，打开的标签页跟随新路径。新建和另存为使用填写的文件名，遇到同名可换名或保留两者。
- 保存原文件时保留原所有者和所属组，按 Linux 规则恢复原权限位。无法保留所有权或权限不足时，保留原文件和草稿，显示文件路径与失败原因，并提供「另存为」。打开文件权限不足时显示文件路径与原因。需要从网页编辑受保护且格式受支持的文件时，从管理员模式的文件管理器打开。

## 管理员模式

- 普通账号运行时，操作者可在文件管理器窗口内显式开启「管理员模式」。窗口持续显示模式状态，关闭窗口或刷新页面后恢复普通模式。普通操作遇到权限错误时保留原有错误提示，操作者可自行开启管理员模式。root 启动时，窗口显示当前身份为 root。
- 管理员模式涵盖目录浏览、下载、流式打包下载、压缩、解压、上传、新建、重命名、复制、移动、删除、修改所有权和权限。复制、移动、另存为的目标目录对话框以及同名冲突处理，沿用发起操作时的身份。批量操作的各项请求使用同一发起身份。从管理员模式窗口执行「在此打开终端」仍以 goDesk 运行账号启动终端，不会隐式打开 root Shell。
- 从管理员模式窗口打开的编辑和只读预览标签页使用管理员身份读取，并显示权限状态。编辑标签页保存和另存为时沿用打开时的身份。独立打开的编辑器使用运行账号。同一路径以不同身份打开时各自保留标签页及草稿。
- 管理员操作沿用现有的删除确认、流式上传和下载以及逐项结果。sudo 拒绝执行时显示失败原因，编辑器保留草稿。已完成部分沿用既有结果和错误语义，例如跨挂载点移动的源清理失败。授权方式见[主机权限契约](privileges.md)。

## HTTP 接口

所有接口使用现有操作者会话，前缀为 `/api/v1/files`。路径为 Linux 绝对路径，名称为单个目录项。

文件操作接口接受可选查询参数 `elevated=true`，用于显式请求 root 执行；省略该参数或传 `elevated=false` 时使用运行账号。请求体和响应沿用下表契约。管理员下载先使用 HEAD 检查可读性，随后由浏览器直接流式下载。无效参数返回 `400`（`invalid_request`）；请求提权但 sudo 无法执行时返回 `403`（`permission`）。

| 方法和路径 | 请求 | 成功响应 |
| --- | --- | --- |
| `GET /identity` | | `{root}`，表示服务是否以 root 运行 |
| `GET /directory` | 查询参数 `path`，省略时打开主目录 | `{path, home, entries}` |
| `POST /action` | JSON `{operation, path, destination?, name?, conflict?}` | `{path}`，跳过时附 `skipped: true`，跨挂载点移动成功时附 `copied: true` |
| `PUT /ownership` | JSON `{path, owner?, group?}`，至少提供一项 | `{path}` |
| `PUT /permissions` | JSON `{path, mode}`，`mode` 为三位或四位八进制字符串 | `{path}` |
| `POST /upload` | 查询参数 `directory`、`name`、`conflict?`，请求体为 `application/octet-stream` 文件字节 | `{path}`，跳过时附 `skipped: true` |
| `GET /download` | 查询参数 `path` | 附件形式的文件字节 |
| `HEAD /download` | 与下载相同 | 与下载相同的状态及响应头 |
| `GET /archive/download` | 重复查询参数 `path` | 附件形式的流式 ZIP 字节 |
| `HEAD /archive/download` | 与打包下载相同 | 预检可读性，返回相同状态及响应头 |
| `POST /archive/compress` | JSON `{paths, destination, conflict?}` | `{path}` |
| `POST /archive/extract` | JSON `{path, destination?, mode, conflict?}` | `{destination, extracted, skipped}` |
| `GET /image` | 查询参数 `path` | 浏览器内显示的图片字节和对应的媒体类型 |
| `HEAD /image` | 与图片预览相同 | 与图片预览相同的状态及响应头 |
| `GET /text` | 查询参数 `path` | `{path, text, version}` |
| `PUT /text` | JSON `{path, text, version?, conflict?}` | `{path, version}` |

`entries` 每项包含 `name`、`path`、`kind`、`size`、`owner`、`group`、`permissions`、`mode`、`modTime`。其中所有者和所属组为显示名称或数字字符串。`mode` 为四位八进制权限字符串，`modTime` 为 RFC 3339 UTC 修改时间戳。符号链接附带 `targetKind` 或 `targetError`。目录类型为 `directory`，普通文件为 `file`，符号链接为 `symlink`。

`operation` 取 `mkdir`、`rename`、`copy`、`move` 或 `delete`。新建时 `path` 是父目录。重命名和新建提供 `name`。复制和移动提供目标目录 `destination`。批量由前端逐项调用，保留每项结果。未指定 `conflict` 时返回同名错误。复制、移动、上传、压缩和解压接受 `keep` 或 `skip`，创建文本接受 `keep`。解压支持 `.zip`、`.tar`、`.tar.gz`、`.tgz`，`mode` 取 `folder`（解压到同名文件夹）或 `here`（解压到当前目录）。

文本接口按内容接受任意文件名下无 NUL 字节且不超过 5 MiB 的 UTF-8 文本。读取时最多读取 5 MiB 加一个字节以判断是否超限。保存原文件时传入读取或上次保存取得的 `version`。编辑器在实际目标目录中写入临时文件，再原子替换原文件，因此保存原文件需要写入该文件和实际目标目录的权限。创建文本时省略版本。

文件操作失败返回 JSON `{code, message, path?}`。未登录返回 401。常见错误包括路径无权限（403，`permission`）、路径不存在（404，`not_found`）、同名或版本变化（409，`exists` / `changed`）、文本超限（413，`text_too_large`）、越界归档路径（400，`path_traversal`）、损坏归档（400，`invalid_archive`）。文本与归档接口的 415 响应区分不支持的文件/归档类型（`unsupported_type`）、含 NUL 的二进制内容（`binary_file`）和不支持的文本编码（`unsupported_encoding`）。跨挂载点移动无法清理源时，`code` 为 `source_cleanup_failed`，`path` 为已完成的目标路径。

无效账号和无效权限分别返回 `invalid_account` 和 `invalid_mode`（400）。保存原文件时无法保留所有权返回 `ownership_preservation_failed`（403）。
